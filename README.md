# GoLan

Two-way communication bridge for service counters (hospital, bank, office): a Deaf signer's hand signs are recognised **on the device**, turned into one polite sentence by Gemma on the server, and spoken aloud; staff speech is captioned and shown to the signer as animated signs.

This repo is the consolidation of the `brain` (API + contract), `nish` (MediaPipe vision) and `vishal`/`signbridge-fixed` (UI + avatar) snapshots into **one** Next.js app.

## Flow

camera permission → MediaPipe hand landmarks → normalise + match against the sign pack (`lib/vision/*`) → session buffer, 1.5 s pause (`lib/session.ts`) → one validated `POST /api/compose` → Gemma (server-side key) → sentence shown + spoken. The UI labels the result as **live**, **mock** or **fallback**.

## Setup

Requirements: Node.js ≥ 20.9, npm, a browser with a camera (served from `localhost` or HTTPS).

```bash
npm install            # also copies the MediaPipe WASM into public/mediapipe/wasm (postinstall)
cp .env.example .env.local   # Windows PowerShell: Copy-Item .env.example .env.local
npm run dev            # http://localhost:3000
```

### Environment variables (server only, `.env.local`)

| Variable | Meaning |
| --- | --- |
| `MOCK_GEMMA` | `true` = demo text, no network call (default in `.env.example`). Set `false` for real generation. |
| `GEMINI_API_KEY` | Google AI API key. Required when `MOCK_GEMMA=false`; if missing the API answers `503 not_configured` (it never silently mocks). |
| `GEMMA_MODEL` | Model id, default `gemma-4-26b-a4b-it`. **Check it is available to your key/account** (a wrong id returns `provider_error`). |

`.env*` files are git-ignored except `.env.example`. The key is only read in `lib/gemma.ts` (server). If a key was ever committed, revoke it.

## Sign packs

One recogniser, one format (`public/packs/default.json`):

```json
{ "version": 1, "name": "default", "examples": [ { "label": "HELP", "frames": [ /* 16 × 63 numbers */ ] } ] }
```

Packs are validated on load (`lib/vision/pack.ts`); a malformed or old-format (`maxDistance/signs/templates`) pack shows an error instead of being silently used. To add signs: start the studio, type a label, **Record**, **Save clip**, repeat a few times, **Download pack**, and replace `public/packs/default.json`.

MediaPipe assets (single canonical path): `public/mediapipe/hand_landmarker.task` (tracked) and `public/mediapipe/wasm/` (generated by `npm install`, git-ignored). If local files fail to load the app falls back to the jsDelivr CDN at the same package version (`1.1.1`; keep `lib/vision/recognizer.ts` and `package.json` in sync).

## API

Errors always look like `{ "error": { "code", "message" } }`: `400 invalid_json | invalid_request`, `413 payload_too_large`, `429 rate_limited`, `502 provider_auth | provider_error`, `503 not_configured`, `504 timeout`.

`POST /api/compose`
```json
{ "signs": ["HELP","HOSPITAL"], "scenario": "hospital", "lang": "en",
  "history": [ { "who": "signer", "text": "I need help." }, { "who": "staff", "text": "How can I help?" } ] }
```
→ `{ "sentence": "...", "source": "live" | "mock", "fallback": false | true, "summary": {...} }`

`scenario`: `hospital | bank | office`. `lang`: `en | hi | mr`. `history`: max 20 turns. Types live in `lib/types.ts` and are shared by client and server. `POST /api/simplify` (`{speech, scenario, lang}`) is available but not yet wired into the UI.

The server aborts model calls after 10 s (real `AbortSignal`), logs only an error category (never keys or conversation text), and the client shows `source: "fallback"` + the reason when it has to fall back to the raw sign words.

```text
  api/compose/       POST /api/compose
  api/simplify/      POST /api/simplify

```

## Known limitations

- Recognition covers only the signs in the pack (the shipped pack has 12 examples) and is experimental; not for sole use in emergency, medical or financial decisions.
- The avatar's sign library is ASL-based approximations, not ISL; have a Deaf signer review it.
- Browser speech recognition may send audio to a cloud service.
- Recognised sign words and a few recent sentences are sent to the server/Gemma; camera video never leaves the device.
